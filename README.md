# Currency Exchange — by SAYFODROID

A single-file currency converter (default **USD → AMD**) with live rates for ~160 currencies.

## Features
- Live rates on startup (offline fallback for major currencies)
- Language picker on first launch: Հայերեն, Русский, English, العربية, plus more
- Searchable currency picker with back buttons, clear button on the amount field
- 2-second logo splash, light/dark theme

## Run
Open `index.html` in any browser. No build step, no dependencies.

## Rates
Fetched from the free `open.er-api.com` endpoint. Rates are indicative, not financial advice.

## Verify integrity
```
sha256sum -c SHA256SUMS
```
